# Add-ons descargables de ARSENAL, legibles

> El `.md` de cada carpeta está **GENERADO** a partir del `.adu`/`.tmp` que tiene al lado.
> Regenerar: `python3 herramientas/decodificar-addons.py`

Cada manifiesto con su lectura en Markdown al lado: nadie tiene un editor de `.adu`, y en un
proyecto de descompilado lo descifrado debe poder leerse sin herramientas. Crudo y legible van
juntos (y no en un `source-…` aparte) porque el crudo son 51–520 B de lista de nombres.
